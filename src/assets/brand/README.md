# Splash branding

- `deegee-games.svg`: full dark transparent lockup from the user-supplied `deegee-games-brand-pack.zip`, extracted as `deegee-brand/svg/deegee-lockup-dark-transparent.svg`. Used on charcoal according to the supplied brand guide. Wordmark lettering is outlined; its Montserrat font license is retained in `deegee-games-OFL.txt`.
- `ecspresso.svg`: full dark transparent master logo copied from `../ecspresso/assets/brand/ecspresso-master-dark-transparent.svg`. The source brand guide identifies it as derived from David's supplied artwork.

These files are bundled locally so launch screens also work offline.

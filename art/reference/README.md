# Art references

These assets are retained for future art work and are not imported by the game or included in its builds.

- `fly/fly-forward-seed.png`: detailed front-facing reference for the current fly design.
- `fly/fly-direction-model.png`: front, side, and rear views of that design.
- `fly/fly-wingless-model.png`: side and rear body/leg references without wings obscuring them.
- `button-prompts/{keyboard,xbox,playstation,switch,steamdeck}/`: spare glyphs from the existing prompt set. Move a glyph into the corresponding `src/assets/button-prompts` folder when adding a runtime caller.

Approved runtime sheets live in `src/assets/sprites`. Superseded designs and unused animation iterations do not belong in this reference collection; Git history retains their previous versions.
